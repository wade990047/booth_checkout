# 可匯入的範例資料

[下載範例 JSON](https://raw.githubusercontent.com/wade990047/booth_checkout/master/data/examples/booth-example.json)

這是虛構示範資料，含 10 件商品、6 個分類、6 種優惠活動、2 組優惠碼與商品示意圖片，沒有交易紀錄或私人資料。商品起始庫存均為 30，展示品販售開啟。

在網站按「匯入備份」並選擇此 JSON。**匯入會取代目前資料，不會合併；請先匯出自己的備份。** 可在另一個瀏覽器試用。以下測試均先清空購物袋，不使用優惠碼。

| 測試 | 加入商品 | 預期結果 |
| --- | --- | --- |
| 套組一組條件 | SET-1 ×2、SET-2 ×2、SET-3 ×1 | 僅1件 A 優惠50，總額260元。 |
| 套組兩組條件 | SET-1 ×2、SET-2 ×4、SET-3 ×2 | 2件 A 各50元，總額320元。 |
| 每2件優惠價 | PRICE-1 ×2、PRICE-2 ×2 | 2件較低價商品各30元，總額360元。 |
| 每2件六折 | RATE-1 ×2、RATE-2 ×2 | 2件較低價商品各72元，總額444元。 |
| 滿額贈一次 | GIFT-1 ×2 | 自動加入 FREE-1 ×1，贈品0元，總額500元。 |
| 滿額贈上限 | GIFT-1 ×6 | 自動加入 FREE-1 ×2，贈品0元，總額1500元；將活動上限留白後會送3件。 |
| 分類訂單折抵 | ORDER-1 ×2 | 原價400，折30，總額370元。 |
| 全單訂單折抵 | GIFT-1 ×20 | 自動送2件徽章，全單5000折500，總額4500元。 |

優惠碼 DEMO10 為折抵10%（九折），DEMO50 為折抵50元，每單擇一。以 PRICE-1 ×2、PRICE-2 ×2 為例，原應收360元，套用 DEMO10 後324元，改用 DEMO50 後310元。

混合不同範例時仍會依完整購物袋判斷活動，訂單滿額活動只採最優惠的一個。正式收銀前請換回自己的備份，避免將範例訂單當成實際交易。

# 小攤日常｜攤位結帳系統操作說明

小攤日常是以 HTML、CSS、JavaScript 製作的攤位收銀工具，提供商品選購、庫存總覽、交易紀錄、優惠活動與頁面設計五個功能頁面。金額以新臺幣（NT$）計算。

- **正式網站：** https://wade990047.github.io/booth_checkout/
- **程式碼：** https://github.com/wade990047/booth_checkout
- **適用方式：** 單一裝置、單一瀏覽器進行收銀。
- **資料保存：** 商品、圖片、庫存、交易、優惠與設計儲存在目前瀏覽器，不會因部署網站而自動上傳至 GitHub。

> 「結帳」會記錄交易與更新庫存，沒有串接刷卡、電子支付、發票或實際收款服務。請自行完成收款，再按結帳。

## 第一次使用與每日流程

### 第一次使用

1. 開啟正式網站，固定使用同一個瀏覽器與網址。
2. 已有舊網站資料時，先在舊站「匯出備份」，再到新站「匯入備份」。新網址不會自行讀取舊網址資料。
3. 沒有資料時，按「新增商品」，建立分類、商品編號、價格與庫存。
4. 到「優惠活動」新增活動與優惠碼，並用購物袋檢查金額是否符合預期；檢查後按「取消」清空，不必建立測試交易。
5. 到「頁面設計」調整名稱、配色和圖示，按「儲存設計」。
6. 匯出一份初始備份。

空白首頁也可按「試用範例商品」了解介面。範例資料僅供試用，正式使用前請確認商品與庫存。

### 每日操作

| 時機 | 建議操作 |
| --- | --- |
| 開攤前 | 確認商品價格、目前庫存、活動設定及裝置日期時間，匯出備份。 |
| 每筆交易 | 選商品 → 調整數量 → 確認優惠／自動加入商品 → 套用優惠碼 → 確認應收金額 → 收款 → 結帳。 |
| 收攤後 | 查看交易紀錄及庫存總覽，匯出當日備份。 |

左側選單切換頁面會保留購物袋。重新整理、關閉頁面或直接開啟其他 HTML 入口，尚未結帳的購物袋不會保存。

## 商品選購

**用途：** 找商品、建立購物袋、即時計價與結帳。

### 找商品與查看商品卡片

- 上方「所有」顯示全部商品；點分類只顯示該分類。
- 搜尋框可輸入商品名稱或完整商品編號，搜尋結果仍受目前分類限制。
- 商品依完整編號自然排序，例如 2 排在 10 前面，由左至右排列。
- 卡片顯示圖片、完整編號、名稱、原始定價與目前庫存。實際優惠價以購物袋計算為準。
- 左上角「組合優惠」代表商品可能直接獲得單價折抵，不表示這次購物已達標。
- 下方「n 項優惠活動」表示相關活動數量。只作為綁定條件、滿額門檻或訂單折抵範圍的商品，不會因此出現左上角單價優惠標記。
- 右上角「⋯」可編輯商品。

### 購物袋與結帳

1. 點商品圖片加入 1 件，以「＋／−」或數量輸入框調整。輸入超過可販售上限時自動改為上限（包含已開啟的展示品 1 件），離開欄位時更新；0 會移除商品，小數向下取整。
2. 在購物袋按「×」移除該品項；按下方「取消」清空整袋及優惠碼。
3. 優惠碼輸入框上方會顯示與袋內商品相關的優惠活動，包括尚未達標的活動。
4. 滑鼠移入或點擊活動名稱，查看所需商品、件數、金額門檻、目前差額與優惠內容。
5. 輸入優惠碼後按「套用」或 Enter，確認是否顯示套用成功。
6. 檢查「商品小計」、「優惠折抵」及「應收金額」。商品小計為原價總額，優惠折抵包含商品、訂單及優惠碼折抵。
7. 完成實際收款後按「結帳」：建立交易、扣除商品庫存、清空購物袋與優惠碼。

結帳區右上角按鈕可向右收合；商品區會擴大，按上方「購物袋」可重新展開。

### 展示品與可售上限

到「庫存總覽」找到該商品的「販售展示品」勾選框，變更後立即保存。

- **未勾選：** 可售數量以目前庫存為限，庫存 0 時圖片變灰、顯示「已售完」，不能加入購物袋。
- **已勾選：** 額外允許販售 1 件展示品。庫存 0 時顯示「展示品 1 件」，最終庫存最低為 −1，之後停止販售。
- 新建立商品預設勾選；既有商品已關閉的設定保持不變。舊版商品及舊備份沒有此欄位時，保留原本允許販售展示品的行為。
- 關閉開關時，購物袋超出可售庫存的數量會自動縮減；滿額贈與結帳也使用同一上限。
- 開關不會修改已完成交易或返還庫存。若以前已售出展示品而庫存為 −1，關閉後仍保留 −1，直到補貨或刪除相關交易。

## 新增與編輯商品

**入口：** 上方「新增商品」、商品卡片「⋯」，或庫存總覽的「編輯」。儲存後，商品與庫存資料會同步更新。

### 商品欄位

| 欄位 | 用途與填寫方式 |
| --- | --- |
| 商品名稱 | 必填，最多 80 字。 |
| 商品編號 | 必填，填原始編號，最多 30 字；分類前綴由系統組合。完整編號不可重複，大小寫視為相同。 |
| 商品分類 | 選擇既有分類，或按「＋」新增。 |
| 分類編號 | 選填。填入後成為該分類所有商品的編號前綴；留白為不啟用。 |
| 商品定價 | 原始單價，填 0 或正整數。 |
| 印製庫存 | 印製數量參考欄位，填 0 或正整數，不直接增加可售庫存。 |
| 起始庫存 | 用來計算目前庫存的基準，填 0 或正整數。已有交易時，不可調低到使目前庫存小於 −1。 |
| 商品圖片 | 上傳後裁切與套用，再儲存商品。未上傳時使用預設插畫。 |
| 商品優惠設定 | 可設定一組基本商品優惠；需要多組活動時使用「優惠活動」頁面。 |

新增商品會依所選分類的最大數字編號自動填入下一號（仍可修改），例如已有 chichi-1 時預填 2。若指定數字編號重複，新商品使用指定編號，原商品移到同分類最大數字 + 1；其他分類或非數字編號衝突仍會阻止儲存。歷史交易會同步顯示改號後的商品編號。

### 分類與分類編號

1. 點分類選單旁「＋」。
2. 輸入新分類名稱及選填的「分類 ID」，按「新增分類」。分類不可重名，也不能使用保留名稱「所有」。
3. 既有分類的前綴可在分類選單下方修改，再按「套用分類編號」立即套用；也可隨「儲存商品」一起套用。

例如分類 ID 為 `LT-`、商品編號為 `001`，完整編號就是 `LT-001`。系統不會自行添加連字號，若 ID 是 `LT`，結果就是 `LT001`。

修改前綴會影響**同分類全部商品**，完整編號重複時會阻止儲存；歷史交易中的商品編號也會同步更新，金額與數量保持不變。「新增分類」與「套用分類編號」會直接保存，之後取消商品視窗不會撤銷這些分類變更。

### 移除分類

1. 前往「庫存總覽」，按「管理分類」。
2. 清單顯示各分類名稱、分類編號及商品數量。
3. 按「移除分類」並確認。商品會移至系統「無分類」，保留完整商品編號；使用此分類的優惠活動同步移除。「無分類」不可刪除。
4. 移除後會同步清除分類編號及首頁分類選項，不刪除商品或歷史交易。

有商品時，先編輯商品並改選其他分類；分類滿額贈、指定分類訂單折抵或按分類計算的第 n 件活動仍使用該分類時，先修改或移除相關活動。無法移除的原因會直接顯示在清單中。「所有」是系統篩選選項，不是可移除的分類。

### 商品圖片裁切

1. 選擇圖片檔，進入裁切視窗。
2. 調整縮放、水平位置與垂直位置。
3. 設定正方形輸出邊長，允許 **100–1000 px**。
4. 按「套用圖片」回到商品表單，再按「儲存商品」。

輸出尺寸是圖片檔案尺寸；商品卡片使用統一圖片區域顯示，並不是依上傳像素大小放大卡片。背景與全體圖片位移在「頁面設計」調整。

### 商品表單中的基本優惠

- 「優惠價」留白代表不啟用；填 0 代表符合條件後免費。
- 設定活動名稱、本商品最低購買件數、每筆最多折扣件數。
- 可勾選其他商品及最低件數；所有勾選條件必須同時滿足。
- 綁定清單優先顯示同分類商品，再按分類及商品編號排列；可搜尋名稱、編號或分類，搜尋不會清除已勾選項目。
- 這組優惠會出現在「優惠活動」清單。更多規則請見下文。

### 刪除商品

編輯商品後按「刪除商品」。有交易紀錄的商品仍不可刪除。其餘商品可直接刪除，活動中的綁定會同步移除；若刪除的是折扣商品，或受影響活動只剩一種商品（或沒有商品），該活動也會刪除。單筆與批量刪除適用相同規則。

## 庫存總覽

**用途：** 查看商品資料、剩餘數量與累計販售量，並進入商品編輯。

頁面上方顯示商品總數、目前庫存合計與累計售出。勾選表格上方的欄位開關，可顯示或隱藏下列資料：

| 欄位 | 說明 |
| --- | --- |
| 商品編號 | 分類前綴與原始編號組成的完整編號。 |
| 商品名稱 | 已設定的名稱。 |
| 商品分類 | 所屬分類。 |
| 商品定價 | 原始單價。 |
| 商品印製庫存 | 獨立參考數字。 |
| 商品起始庫存 | 計算目前庫存的基準。 |
| 商品目前庫存 | 自動計算，不可直接編輯。 |
| 商品販售數量 | 仍存在交易的商品件數合計，不可直接編輯。 |
| 販售展示品 | 每列直接勾選／取消，決定是否額外允許販售 1 件展示品，立即保存。 |

**目前庫存 = 起始庫存 − 販售數量。**

例如起始庫存 10、已售 3 件，目前庫存為 7。補貨 5 件時，可把起始庫存改為 15，目前庫存就會變為 12；不要直接把起始庫存填成 12，否則會再次扣除已售 3 件。

自動加入的贈品只要完成結帳，也會計入販售數量並扣庫存。表格上方的欄位顯示開關只改變表格呈現，不影響計算；真正的展示品販售設定位於表格內每一列。

### 批量庫存操作

庫存與商品管理視窗均有分類下拉選單。切換分類會清除勾選；全選僅選目前分類，避免操作隱藏商品。庫存統計也依篩選結果顯示。「所有商品庫存歸零」仍作用於全部商品。

先勾選表格每列最左側的選取框，或用表頭全選；欄位顯示開關與商品選取是分開的。

- **所有商品庫存歸零**：確認後將全部商品的「起始庫存」改成累計售出量，使目前庫存為 0。保留交易紀錄、印製庫存及展示品設定。展示品仍開啟時可額外出售 1 件；之後刪除舊交易仍會返還庫存。
- **商品管理**：勾選多個商品後按「刪除所選商品」並確認。若任一商品仍有交易，整批不會刪除；沒有交易的商品可刪除，相關優惠依上述規則清理。建議刪除前匯出備份。
- **所選商品：開啟／關閉展示品**：合併為一個按鈕；所選商品全開時顯示關閉，否則顯示開啟。確認後統一更新所選商品，購物袋數量會配合庫存上限調整。新商品預設開啟；關閉後庫存 0 即停止販售。
- **匯出所選 CSV**：僅匯出勾選商品與目前顯示欄位，按商品完整編號自然排序，包含即時計算的庫存及售出數量。採 UTF-8 編碼，適合以試算表開啟；CSV 是報表，不能代替可還原的 JSON 備份。若沒有選取商品或顯示欄位，按鈕停用。

## 交易紀錄

**用途：** 查閱已結帳訂單、銷售總額、商品明細，以及刪除誤建交易。

每筆交易顯示編號、日期時間、商品編號與名稱、下單數量、價格明細、套用的活動／優惠碼及交易金額。新交易列在上方；頁面另顯示累計交易金額、交易筆數與售出件數。

- 每筆交易的商品明細按同步更新後的完整商品編號（ID）自然排序，例如 2 在 10 前，不依加入購物袋順序；既有交易也適用此顯示順序。
- 「刪除所有紀錄」須連續確認兩次，才會刪除全部交易並返還庫存；任何一次返回或關閉都不執行。下一筆編號從 #0001 開始。無法直接復原，請先匯出備份。
- 商品設定或優惠活動之後修改，不會重算既有交易。
- 「刪除並返還庫存」會在確認後刪除整筆交易，返還所有商品數量，包含贈品。
- 這不是部分退貨或實際退款功能，也沒有單筆撤銷刪除按鈕；需要保留資料時請先備份。
- 下一筆編號為「目前仍存在的最大交易編號 + 1」，既有交易不重新編號。

編號範例：有 #0001、#0002、#0003 時，刪除 #0003，下一筆為 #0003；只刪除 #0002 而 #0003 仍存在，下一筆為 #0004。全部刪除後下一筆從 #0001 開始。

## 優惠活動

**用途：** 集中管理優惠碼與所有優惠組合。同一商品可建立多個活動，各自命名與修改條件。

### 建立與維護

1. 先建立活動需要的商品與分類。
2. 進入「優惠活動」，按「新增優惠活動」。
3. 填入活動名稱、選擇類型，依下文設定相應欄位。
4. 按「儲存優惠活動」。
5. 已有活動可按「設定」修改，或按「刪除」並確認移除。修改／刪除活動不改動歷史交易。

活動沒有排程起訖時間；儲存後即參與計價。購物袋會自行判斷條件，不需手動選擇活動。

### 六種類型速查

| 活動類型 | 適合用途 | 達標基準 | 折抵對象 |
| --- | --- | --- | --- |
| 商品優惠組合 | 買 A、B 後，A 特價 | 折抵商品及所有綁定商品的最低件數 | 指定商品，套用設定單價 |
| 分類滿額贈（指定商品折抵） | 某分類滿額送贈品／加價購 | 手動加入商品的該分類原價小計，及綁定條件 | 自動補入指定商品，每件減固定金額 |
| 全商品滿額折抵（訂單） | 全單滿 500 折 50 | 全商品優惠後小計 | 訂單總額 |
| 指定分類滿額折抵（訂單） | 明信片滿 300 折 30 | 指定分類商品優惠後小計 | 訂單總額，限該分類金額範圍 |
| 第 n 件優惠價（較低價品項） | 任選兩件，較便宜一件 30 元 | 適用商品累計件數 | 最低原價的一件 |
| 第 n 件折扣（較低價品項） | 任選兩件，較便宜一件六折 | 適用商品累計件數 | 最低原價的一件 |

## 六種優惠活動的設定與範例

### 1. 商品優惠組合

**設定：** 選擇折抵商品、最低件數、每件優惠價格、每筆最多折扣件數，以及選填的其他綁定商品與數量。

所有件數條件都必須滿足；條件商品不會被消耗，也不會按組數分配折扣。

範例：A 原價 100 元、B 原價 150 元。設定折抵商品 A、A 最低 1 件、綁定 B 至少 1 件、A 優惠價 60 元、最多折扣 1 件。

| 購物袋 | 計算 | 總額 |
| --- | --- | --- |
| A | 缺 B，不達標 | 100 元 |
| A + B | 60 + 150 | 210 元 |
| A + A + B | 60 + 100 + 150 | 310 元 |

「每筆最多折扣件數」留白表示全部 A 都可折扣；填 1 表示每單最多 1 件。即使條件商品買多組，也不會把這個上限乘以組數。優惠價格不可高於原價。

### 2. 分類滿額贈（指定商品折抵）

**設定：** 選擇折抵商品、折抵商品最低件數、指定分類、滿額門檻、每件折抵金額、每筆最多折扣件數，以及選填的綁定商品。

達到分類門檻及所有綁定條件後，系統會自動補足折抵商品至「最低件數」。

範例：明信片分類滿 500 元，送原價 80 元的徽章 1 件。

| 欄位 | 設定 |
| --- | --- |
| 折抵商品 | 徽章 |
| 折抵商品最低件數 | 1 |
| 指定分類 | 明信片 |
| 滿額門檻 | 500 |
| 每件折抵 | 80 |
| 每筆最多折扣件數 | 1 |

手動加入明信片原價合計達 500 元後，徽章自動加入，優惠單價為 0 元。若每件只折抵 30 元，徽章仍需支付 50 元，屬於加價購，**不是免費贈送**。

自動加入規則：

- 滿額門檻使用手動加入商品的**原價小計**，不是商品優惠後的小計。
- 自動加入的贈品不計入其他滿額贈門檻或綁定件數，避免連鎖觸發。
- 手動購買的折抵商品若屬於指定分類，會計入該分類原價小計。
- 已手動選 1 件、最低件數為 2 時，只自動補 1 件；不是額外再送 2 件。
- 多個活動贈送同商品時，自動數量取所需最大補足數，不相加。
- 不再達標時移除自動加入的數量，保留手動選購的數量。
- 手動移除贈品後，本次達標期間不強制補回；未達標後再次達標，才恢復自動補入。
- 庫存不足以補足最低件數時顯示提醒，不自動加入；可售上限依贈品本身的「販售展示品」設定決定。
- 「最低件數」控制補足數量，「最多折扣件數」控制優惠數量。若前者設 2、後者設 1，可能加入 2 件但只有 1 件折扣。
- 滿額多倍不會重複送多組；折抵後單價最低 0 元。贈品完成結帳仍正常扣庫存。

### 3. 全商品滿額折抵（訂單）

**設定：** 活動類型選「全商品滿額折抵（訂單）」，填滿額門檻與訂單折抵金額。

例如滿 500 折 50：全單商品優惠後小計為 550 元，折抵後為 500 元；如果原價 550 元，但商品優惠後只剩 480 元，就不符合滿 500 的門檻。

這裡的「折 50」是**減少 50 元**，不是五折。每單只折抵一次，不是每滿 500 元就再減 50 元。

### 4. 指定分類滿額折抵（訂單）

**設定：** 選「指定分類滿額折抵（訂單）」，指定分類、門檻及訂單折抵金額。

例如明信片分類滿 300 折 30：明信片優惠後小計 320 元，加上其他分類 200 元，整單為 320 + 200 − 30 = **490 元**。

其他分類不能湊門檻。若明信片只有 280 元，即使整單達 500 元仍不符合。折抵不超過該分類優惠後小計，也不會自動加入商品。

### 5. 第 n 件優惠價（較低價品項）

**設定：** 選適用範圍（指定商品組合或指定分類）、累計件數 n，以及第 n 件優惠價格。

「指定商品組合」可勾選多個商品，代表任選累計件數，不是每種都要買。達到 n 件後，選取適用範圍內**最低原價的一件**套用優惠，與加入購物袋的先後順序無關。

範例：A = 150 元、B = 120 元；設定 n = 2、優惠價 = 30 元。

| 購物袋 | 計算 | 總額 |
| --- | --- | --- |
| A + B | 150 + 30 | 180 元 |
| A + B + B | 150 + 120 + 30 | 300 元 |
| B + B | 120 + 30 | 150 元 |
| A + A + B + B | 150 + 150 + 120 + 30 | 450 元 |

**每筆訂單只優惠一件**，四件也不重複套用兩次。設定的優惠價若高於被選中商品原價，不會把商品漲價。

### 6. 第 n 件折扣（較低價品項）

**設定：** 適用範圍及 n 的方式同上，改填「第 n 件打幾折」。

- 填 `6` = 六折，優惠單價為原價 × 0.6。
- 填 `8.5` = 八五折，優惠單價為原價 × 0.85。
- 優惠單價四捨五入至整數元。
- 每單只折抵最低原價的一件，不按滿足組數重複計算。

範例：A = 150 元、B = 120 元；第二件六折。

| 購物袋 | 計算 | 總額 |
| --- | --- | --- |
| A + B | 150 + 120 × 0.6 | 222 元 |
| A + B + B | 150 + 120 + 120 × 0.6 | 342 元 |

以上活動範例均假設沒有其他活動或優惠碼競合；多活動同時存在時，依下方計算順序處理。

## 優惠碼

**入口：** 「優惠活動」頁面的「新增／管理優惠碼」，或頁面上方「優惠碼」。

1. 輸入代碼，例如 `BOOTH10`。
2. 選折扣方式並填數值。
3. 按「新增優惠碼」。代碼會轉成大寫，不可重複。
4. 結帳時在購物袋輸入代碼，按「套用」或 Enter；輸入比對不區分大小寫。

| 折扣方式 | 填寫範例 | 實際效果 |
| --- | --- | --- |
| 百分比折抵 | 10 | 折抵剩餘金額的 10%，也就是九折。 |
| 固定金額折抵 | 50 | 從剩餘金額減 50 元。 |

百分比數值為 1–100 的整數，固定金額為正整數。百分比折抵金額四捨五入至整元，總額不低於 0。

每單只能套用一組優惠碼。清空輸入框後再按「套用」可取消；取消購物袋或結帳後也會清除。找不到代碼時會提示，該代碼不產生折抵。

目前管理視窗提供新增與刪除，沒有直接編輯按鈕；需要修改同一代碼時，先刪除舊碼再新增。沒有到期日、使用次數上限或會員限制；刪除優惠碼不影響歷史交易。

> 優惠碼的「10」是減 10%；第 n 件折扣的「6」是付六折。兩者輸入意義不同。

## 優惠計算順序

1. 依手動購物內容判斷分類滿額贈，補入符合條件的商品。
2. 計算商品層級優惠：商品組合、分類滿額贈、第 n 件活動。
3. 同一商品若符合多個商品活動，選擇對該商品**總折抵金額最多的一個**，不疊加；不同商品可各自套用活動。
4. 以商品優惠後的小計判斷訂單滿額活動。全商品與指定分類活動之間也只選**折抵最多的一個**。
5. 最後從剩餘金額計算一組優惠碼，應收金額最低 0 元。

第 n 件活動先依原價選出最低價品項，再與該品項的其他優惠比較；不是把整張訂單拆成多組來搜尋最佳組合。活動明細顯示「已達標，採較優惠活動」，表示條件符合，但另一活動折抵更多。

綜合範例：商品原價總計 800 元，商品優惠折抵 100 元後剩 700 元；訂單滿 600 折 50，剩 650 元；再套用百分比折抵 10 的優惠碼，折抵 65 元，最後應收 **585 元**。

## 頁面設計

**用途：** 調整攤位品牌、頁面文字、配色、商品圖片位置與圖示。下列操作名稱以預設文字為準，若已自訂，介面名稱可能不同。

### 預設使用語言

在「頁面設計」最上方的「介面語言」選擇：

- **繁體中文**：既有資料與新安裝的預設語言。
- **English**：英文介面。
- **日本語**：日文介面。

切換後立即預覽，按「儲存設計／Save design／デザインを保存」後，重新整理或下次開啟仍會使用已保存的語言。「放棄變更」會回復上次儲存的語言；尚未儲存就離開設計頁，則不保留預覽。

語言涵蓋側欄、各功能頁、表單、優惠條件說明、庫存提示、圖片裁切與操作訊息。系統預設的網站／頁面名稱及按鈕文字會跟著切換；自行修改的文字與刻意留白會保留。商品名稱、分類名稱、活動名稱、優惠碼和歷史資料不會自動翻譯。

金額仍使用新臺幣 NT$，不進行匯率換算。第 n 件折扣仍採 10 分率輸入：6 表示支付原價 60%（40% off／40%引き）；優惠碼百分比則輸入折抵比例，10 表示折抵 10%。

語言設定保存在目前瀏覽器，並包含在匯出備份內；其他使用者不會因此一起切換。匯入舊版備份若未含語言設定，使用繁體中文。

### 可調整內容

| 區域 | 功能 |
| --- | --- |
| 介面語言 | 繁體中文、English、日本語；儲存後作為預設語言。 |
| 網站與頁面名稱 | 網站名稱、左上副標、五個功能頁面名稱。每頁的選單名稱與頁面標題共用同一設定。 |
| 頁面與按鈕配色 | 商品圖片背景、頁面背景、卡片與選單背景、主要與輔助文字、主題色，以及主要／一般／刪除按鈕背景與文字色。 |
| 按鈕文字 | 修改設定頁列出的新增、結帳、取消、備份、編輯、刪除等按鈕文字，不改變功能。 |
| 左下角自訂文字 | 可換行、可留白；資料儲存狀態仍保留。 |
| 商品圖片位置 | 全體商品圖片上下位移 −100 至 100 px；負數向上、正數向下、0 為原位。向下移動後上方補白。 |
| Logo 與按鈕圖示 | 上傳左上角 Logo、側欄及設定清單內功能按鈕的圖示；同功能共用圖示。 |

所有設計文字欄位皆可留白；若頁面標題消失，先確認對應名稱是否被留白。商品圖片背景影響圖片外圍與透明區域，不會替換圖片檔本身已有的底色。

### 自訂 Logo／圖示

1. 找到對應圖示設定並上傳圖片。
2. 調整縮放、水平／垂直位置及正方形裁切。
3. 輸出邊長可設 **100–1000 px**，圖示顯示尺寸固定 **100 × 100 px**。
4. 套用後確認預覽，最後按「儲存設計」。

個別圖示可恢復預設。只支援圖示設定清單列出的項目；商品照片使用商品表單中的圖片上傳。

### 預覽與儲存

- 修改時即時預覽，**按「儲存設計」才會保存**。
- 「放棄變更」回復上次保存設定。
- 「恢復預設」先預覽預設外觀，仍需再按儲存才生效。
- 離開設計頁前先儲存，避免未保存設定被清除。
- 文字與背景對比偏低時會出現提示，可依提示調整配色。
- 設計設定與上傳圖示會一起包含在備份內。

## 備份與資料搬移

### 匯出

按左下角或庫存頁面的「匯出備份」，下載 JSON 檔。內容包含已保存的商品、圖片、分類、優惠碼、優惠活動、交易紀錄及設計設定，不包含未結帳購物袋或尚未儲存的表單內容。

### 匯入

1. 先匯出目前資料，留一份還原副本。
2. 按「匯入備份」，選擇本系統匯出的 JSON。
3. 確認提示的商品與交易數量，再確認匯入。
4. 匯入會**取代目前資料，不是合併**，並清空購物袋與優惠碼。

格式或資料驗證失敗時不會取代目前資料。不要直接手動修改備份內部欄位。

### 保存範圍

- 同一網址的資料儲存在使用中的瀏覽器，不提供帳號登入或跨裝置同步。
- 換網址、瀏覽器、裝置或本機連接埠，都可能是不同的資料空間。
- 清除網站資料、無痕模式結束或裝置損壞，可能使未備份資料遺失。
- 避免多個分頁同時收銀；本系統沒有多人同步或跨分頁鎖定。
- 圖片也占用瀏覽器儲存空間。大量高解析圖片保存失敗時，先備份，再減少圖片尺寸。
- 請將備份保存在安全的本機或私人儲存位置，不要上傳到公開 GitHub 儲存庫。

## 常見問題

| 問題 | 檢查方式 |
| --- | --- |
| 新網站沒有舊商品 | 不同網址不共用資料，從原網址匯出再匯入。 |
| 圖片變灰不能買 | 未勾選展示品時庫存 0 就停售；勾選時庫存 −1 停售。 |
| 分類無法移除 | 檢查是否仍有商品，或仍被分類優惠活動使用；先移轉商品及調整活動。 |
| 增加印製庫存卻沒增加可售量 | 印製庫存僅供參考，補貨請調整起始庫存。 |
| 優惠有標記卻沒折扣 | 標記代表活動關聯，展開購物袋活動查看缺少條件或是否採另一個較優惠活動。 |
| 滿額贈加入後仍要付費 | 每件折抵小於原價，或折扣件數上限小於加入數量；檢查優惠設定。 |
| 滿額贈沒加入 | 檢查手動商品原價小計、綁定件數、可售庫存，以及是否曾手動移除。 |
| 滿額贈與訂單活動判斷不同 | 前者看手動商品原價，後者看商品優惠後小計。 |
| 四件只套用一次第二件優惠 | 第 n 件活動每單只優惠最低價的一件。 |
| 設計改完又恢復 | 離開前需按「儲存設計」，套用圖片不等於儲存設計。 |
| 刪除中間交易後編號仍有空缺 | 不重新編號，下一筆採仍存在的最大編號 + 1。 |
| 更新程式後網站沒有變 | 本機檔案須提交並推送 master，且 Actions 部署成功；之後再重新整理網站。 |

## 本機啟動與程式維護

### 開啟本機版本

本專案不需 npm 安裝、不使用前端框架，也不依賴 CDN。

1. 可直接開啟根目錄 `index.html`。
2. 長期使用建議安裝 Node.js 後，雙擊 `啟動本機網站.cmd`，開啟 http://127.0.0.1:4175 。
3. 結束本機伺服器時，在啟動視窗按 Ctrl+C。

直接開檔模式的儲存行為可能因瀏覽器而異。正式使用請固定網址與瀏覽器；一般操作以左側選單切換頁面，以保留購物袋。

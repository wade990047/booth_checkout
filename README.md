# 小攤日常｜網頁前端原始檔

匯出來源：正式網站版本 7（20a3a8da8f9dd5a208651950ff6df0e7815190a8）。
純 HTML、CSS、JavaScript，不需 npm 安裝或前端框架，不依賴 CDN。

## 開啟方式
1. 直接雙擊根目錄 index.html 開啟完整網站；使用左側選單切換功能可保留購物袋。
2. 各功能也有獨立入口：pages/<功能>/index.html。
3. 建議需要長期保存資料或跨入口共用資料時，使用「啟動本機網站.cmd」；電腦需已安裝 Node.js。啟動後開啟 http://127.0.0.1:4175。結束時在視窗按 Ctrl+C。
4. 也可將本資料夾交給任何一般靜態網站主機，或以編輯器的本機伺服器開啟。

## 資料與搬移
- 本匯出包含網站程式，沒有擷取原網站瀏覽器中的商品、圖片、交易與自訂設定。
- 請先在原網站「匯出備份」，再於本機網站「匯入備份」。
- 不同網址、瀏覽器及直接開檔模式的儲存空間不一定共用。正式使用請固定網址、連接埠及瀏覽器，定期匯出備份。
- 購物袋是暫存，重新載入或直接開啟另一個 HTML 入口會清空；正常使用左側選單切換不會清空。

## 資料夾
| 路徑 | 內容 |
| --- | --- |
| pages/shop | 商品選購入口與商品卡片 |
| pages/inventory | 庫存總覽入口、欄位顯示與統計 |
| pages/history | 交易紀錄入口與交易明細 |
| pages/promotions | 優惠管理、優惠碼、活動表單與提示樣式 |
| pages/design | 頁面設計、配色、文字、Logo／圖示裁切 |
| features/cart | 購物袋、數量、優惠碼套用、自動贈品同步 |
| features/products | 商品建立／編輯、分類編號與綁定搜尋 |
| features/images | 商品圖片裁切 |
| features/backup | JSON 匯出、匯入與資料驗證 |
| shared/js | 共用計價、狀態、儲存、側欄、事件分派與啟動 |
| shared/css | 共用排版、表格、表單、響應式與品牌樣式 |
| assets/images | 額外靜態圖片的存放位置 |
| data/backups | 自行放置匯出的資料備份 |
| docs | 詳細使用說明 |
| tools | 選用的本機伺服器與檔案檢查 |

## 修改程式
每個功能的動態 HTML 與操作放在同資料夾的 JS 中，HTML 為可獨立開啟的入口。全站共用樣式不重複複製，載入順序保持與原站一致。所有入口載入相同功能檔案，以維持側欄切換與資料一致性。修改入口的載入清單時請同步更新其他入口。

驗證：在本資料夾執行 node tools/check.cjs，可檢查所有入口連結、JS 語法與共用計算案例。

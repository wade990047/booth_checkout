# 小攤日常

直接開啟 `dist/index.html` 即可使用本機版本。正式使用前，請固定使用同一個瀏覽器與同一個網址（或同一個本機檔案路徑）。不同網址、裝置或瀏覽器的資料不會互相同步。

## 開始使用

1. 點「新增商品」，填寫編號、名稱、分類、定價、印製庫存與起始庫存。
2. 分類選單旁的 ＋ 可新增分類。商品圖片可上傳、調整裁切位置和縮放，輸出為 100–1000 px 正方形。
3. 點商品圖加入購物袋，用 ＋／− 調整數量。按「結帳」即儲存交易並扣除庫存；不包含串接刷卡或電子支付。
4. 在庫存總覽可編輯商品並切換顯示欄位。目前庫存與售出數量由交易自動計算，不可直接修改。
5. 刪除交易會將整筆商品數量返還。下一筆交易編號採「仍存在的最大編號 + 1」，不重編既有紀錄。

## 優惠規則

商品優惠價留白代表未啟用；填寫 0 代表免費。當本商品數量達到最低件數，且所選其他商品均達到設定件數時，該商品的全部購買數量均採優惠價。其他商品條件不會消耗或分配件數。

每單可用一組優惠碼。百分比的數值 10 表示折抵 10%（九折）。先計算商品優惠，再折抵整單優惠碼，百分比折抵四捨五入為新臺幣整數，最終金額不低於 0。

## 庫存與保存

目前庫存 = 起始庫存 − 仍存在交易的販售數量。印製庫存為獨立參考欄位，不額外增加可售量。最多可售至 -1，表示展示品已售出；之後商品圖片呈灰色並停用。

資料與圖片存於目前瀏覽器的本機儲存空間。清除網站資料或使用無痕模式可能遺失資料。每次收攤請使用「匯出備份」保存 JSON，換裝置可「匯入備份」。匯入會取代目前資料。此版本供單一收銀裝置使用，不提供跨裝置即時同步；避免多個分頁同時結帳。

首頁預設沒有商品，可按「試用範例商品」加入示意資料。範例圖片為內建插畫，不是實際商品照片。

## 驗證

`node test.cjs` 可驗證組合優惠、優惠碼、零元下限、展示品庫存、交易刪除後庫存回復與編號延續。

## 頁面設計
左側「頁面設計」可修改網站名稱、各頁選單與標題、頁面及按鈕配色、按鈕文字與左下角自訂文字。修改時即時預覽，按「儲存設計」才會保存；「放棄變更」回復已存設定，「恢復預設」先預覽原始外觀，再儲存套用。離開設計頁前請先儲存。設定跟隨本機資料一起匯出／匯入。

### Logo 與按鈕圖示
在頁面設計的「05 Logo 與按鈕圖示」可為左上角 Logo、側邊選單及各功能按鈕上傳圖片。支援縮放、水平／垂直位置與正方形裁切，輸出邊長可設 100–1000 px，顯示固定 100 × 100 px。套用圖片為暫存預覽，需再按「儲存設計」。同功能按鈕共用圖示，支援個別恢復預設；圖片跟隨資料備份。

## 本次修正
優惠綁定可依名稱、完整編號或分類搜尋，切換搜尋不會取消勾選。每筆訂單最多折扣件數留白時全部折扣，填入正整數時僅該件數使用優惠價，不按組數重複觸發；其餘按原價。交易明細會記錄兩種價格，舊交易不重算。
頁面標題與選單名稱合併為單一設定，以既有選單名稱為準。商品圖片改完整置中，可設定背景與 -100 至 100 px 位移，向下補白。背景只影響圖片外圍與透明區域，不會替換圖片本身的底色。
新增分類時可填分類 ID（例 LC-），商品原編號 001 會顯示 LC-001；沒有 ID 時保留原編號。不自動加入分隔符，編輯商品時仍填原始編號。既有無 ID 分類維持不變。

### 優惠活動管理（2026/11/05）
- 左側「優惠活動」集中列出優惠碼、商品組合與分類滿額贈，可新增、修改或刪除；舊商品優惠自動顯示，無須重新建立。
- 同一商品可有多個獨立命名的活動。全部條件同時滿足後，選擇該商品「總折抵最多」的一個；同商品不疊加，折扣件數上限為每筆訂單，不按組數重複觸發。
- 分類滿額贈以指定分類的原價小計判斷門檻（若折抵商品屬於該分類，也會計入）；折抵商品必須加入購物袋。設定的是每件折抵金額，單價最低 0 元。
- 購物袋在優惠碼上方顯示相關活動；滑鼠移入活動名稱或點擊名稱可查看需求商品、數量、目前差額與具體優惠。
- 商品分類下可修改分類編號。按「套用分類編號」立即同步該分類所有商品；或隨「儲存商品」一起套用。留白會移除前綴，重複商品編號會擋下。歷史交易快照保留原編號。
- 綁定商品會先列出折抵商品的同分類商品，再按分類群組與商品編號自然排序；搜尋不會清除已選條件。

### 訂單折抵與第 n 件活動
- 全商品／指定分類滿 n 折 m：以商品優惠後的適用小計判斷。多個訂單活動同時達標時，採總折抵最多的一個；不超過該範圍小計。
- 第 n 件 m 元／m 折：可選指定分類或多選商品範圍，任選累計 n 件即達標。最低原價的一件套用優惠，其他件維持原價；每筆限一次。6 代表六折，8.5 代表八五折，金額四捨五入至整元。
- A=150、B=120：第二件30元時 AB=180、ABB=300；第二件六折時 AB=222、ABB=342。
- 同一商品有多個單品／第 n 件活動時，選擇對該商品總折抵最多的一個；訂單折抵於其後計算，優惠碼最後計算。
- 商品左上「組合優惠」只標記可直接享有單價折抵的商品；參與門檻、綁定或訂單活動的商品，下方顯示相關活動總數。

### 滿額贈自動加入
分類滿額贈的滿額與綁定條件達標後，自動補足至折抵商品最低件數。同商品不重複疊加自動數量。以手動選購商品判斷滿額與綁定條件，自動加入的贈品不會觸發其他滿額贈。未達標時移除自動數量，手動選購數量保留。依原設定折抵，並非一律免費；庫存不足時提示且不自動加入。手動移除贈品後，本次達標期間不強制補回；未達標再重新達標時恢復自動加入。贈品結帳時正常扣庫存，交易刪除後返還。
